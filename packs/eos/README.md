# @motion-community/pack-eos

EOS terminology pack for [Motion](https://github.com/OscarCGPro/motion) (community, **unofficial**). Renames Motion's concepts to the terms used by companies running on EOS (Rocks, Level 10, V/TO, IDS...) and adds a Level 10 meeting template.

EOS(R), Traction(R), Level 10 Meeting(TM), V/TO(TM) and related terms are trademarks of EOS Worldwide, LLC.
This pack is not affiliated with or endorsed by EOS Worldwide. Motion shows the attribution while the pack is active.

## Install

In Motion: Settings -> Terminology -> Import pack, then either

- paste the npm name `@motion-community/pack-eos`,
- upload [`pack.json`](pack.json), or
- paste a URL to `pack.json` (for example the raw GitHub URL).

Review the preview, apply, and revert at any time. Self-hosters can preinstall it with `MOTION_TERMINOLOGY_PACKS=@motion-community/pack-eos`.

The package is data only (`pack.json`); no code runs. Format: [terminology packs](https://github.com/OscarCGPro/motion/blob/main/docs/terminology-packs.md).
